## 五、通过标准与失败判定规则

- **通过**：四项质量门禁全绿 + 新增 P0/P1 用例 100% 通过 + 黑盒 7 项符合预期。
- **失败判定**：任一 P0 用例失败 → 禁止合并 `main`；任一门禁出现 warning/error → 视为失败；黑盒出现密钥外泄、沙箱逃逸、SSRF 成功命中内网 → 立即阻断发布并上报安全负责人。
- **本次结论**：**全部通过**，可进入预发布评审（部署目标仍需确认）。
